## 1. 快捷键与基础输出

### 1.1 编辑器快捷键

| 快捷键 | 作用 |
|--------|------|
| `Ctrl + /` | 单行注释 |
| `Shift + Alt + 。` | 放大字体（`Shift + Alt + ，` 为缩小字体） |

### 1.2 注释与语句

- 在一串文字前加 `#` 就是注释写法。
- Python 中一行 `print` 代码写完**不需要**再加 `;` 表示语句结束。

```python
# 这是一行注释
print("Hello Python")
```

### 1.3 数字与小数位控制

- `round(number, n)` 用来保留小数位：`number` 是要输出的数字，`n` 是要保留的位数。
- 输出 float 类型变量时，也可以用 `f"{a:.nf}"` 控制小数点后位数（`n` 表示最终保留几位）。

```python
a = 3.14
print(f"{a:.1f}")     # 3.1
print(round(3.14159, 2))   # 3.14
```

### 1.4 字符串乘法批量打印

- `print("-" * 30)` 含义为把 `"-"` 打印 30 遍。
- `*` 不仅有乘法的含义，用在上述语句中还可以**批量打印字符**。

## 2. 字面量、常量与标识符

### 2.1 字面量

在程序中，直接书写的固定值（数据），就称为字面量（例如 `8.7`、`"Python"`）。

| 描述 | 分类 | 标准名称（括号里） | 说明 |
|------|------|--------------------|------|
| 数字类型 | 整数 | 整数（int） | `10` `2` `-9` `0` |
|  | 浮点数 | 浮点数/小数（float） | `0.3` `3.14` `1.0` `-0.4` |
|  | 布尔 | 表达生活中的逻辑，真假（bool） | `True` `False` |
| 字符串 | — | 描述文本的一种类型（str） | `"你好，Python"` |
| 空值 | — | 表示空，仅有值 None（NoneType） | `None` |
| 数据容器 | — | 储存多项数据的容器 | 列表 / 元组 / 集合 / 字典 |

### 2.2 常量

- 常量：不会发生变化的数据。
- 定义：`PI = 3.1415`（标识符需要**全大写**）。
- 注意：这只是 Python 规范，严格意义上这还是变量。

### 2.3 标识符

标识符是程序员在代码中为变量、函数、类等元素所起的名字。

命名规则：

1. 只能包含字母（a-z、A-Z）、数字（0-9）、下划线（`_`）。
2. 不能以数字开头。
3. 不能使用关键字：`True`、`False`、`None` 等。
4. 严格区分大小写，比如 `age`、`Age`、`AGE` 是三个变量。

### 2.4 查看数据类型

- `type(要查看类型的数据)` 得到数据的类型。
- `isinstance(数据, 类型)` 检查数据是否属于指定类型，返回一个 bool 值。

```python
print(type("Hello"))        # 查看字面量

num = 5.0
print(num)
print(type(num))            # 查看变量 -> <class 'float'>
print(isinstance(num, int)) # False
```

> 注意：变量本身是没有类型的，它输出的类型是**变量中存储的数据**的类型。

### 2.5 变量

变量是程序中用来存储单个数据的容器（存储数据的小空间）。例如 `a = 10` 中的 `a` 就是变量名。

## 3. 字符串

### 3.1 三种定义方式

```python
s1 = "Hello"          # 双引号定义
s2 = 'Python'         # 单引号定义
s3 = """你好
欢迎使用Python"""      # 三引号定义
```

> 三引号中的内容输出是**原封不动**的（保留换行与缩进）。

字符是文本世界的基本单位：一个字母、一个数字、一个标点符号、一个汉字等都是一个字符。

### 3.2 字符串格式化

**方式一：`%` 占位符**

通过 `%`（占位符）的形式完成字符串和变量的快速拼接。其中 `%` 表示"我要占位"，`s` 表示把变量转为字符串放入占位的位置。

```python
s1 = "Joy"
print("大家好，我是%s，欢迎大家进入Python课程的学习" % s1)

s1 = "原神"
s2 = "启动"
print("我说：%s，%s" % (s1, s2))
```

> 前面有多少个占位符（`%s`），后面就需要有多少个变量（或数据），前后数量必须一致。

**方式二：f-string**

通过 `f"内容{变量/表达式}"` 的形式来完成快速格式化。

```python
name = "涛哥"
print(f"大家好，我是{name}，欢迎大家进入Python课程的学习")

s1 = "人生苦短"
s2 = "及时行乐"
print(f"名言是：{s1}，{s2}")
```

### 3.3 转义字符

| 转义字符 | 名称 | 作用 |
|----------|------|------|
| `\'` | 单引号 | 表示单引号 `'` |
| `\"` | 双引号 | 表示双引号 `"` |
| `\n` | 换行符 | 开始新的一行（换行） |
| `\t` | 制表符 | 增加缩进，缩进一个制表符（Tab）的大小 |

当输出 `a = 'It's very good'` 时，`It` 右边的单引号会导致代码错误，把它换成 `\'` 即可（双引号同理）。

```python
a = 'It\'s very good'
```

### 3.4 输入与输出

输入：获取键盘上的信息，用法为 `s = input(提示信息)`。

```python
name = input("请输入你的年龄：")
print("你的年龄是：", name)
```

## 4. 运算符

### 4.1 算术运算符

算术运算符是用于执行基本数学运算的符号，作用于一个或多个操作数上，并产生一个计算结果。

| 运算符 | 描述 | 举例说明 |
|--------|------|----------|
| `+` | 加法 | `1+5`：1 加上 5 |
| `-` | 减法 | `8-3`：8 减去 3 |
| `*` | 乘法 | `3*8`：3 乘以 8 |
| `/` | 除法 | `10/5`：结果是小数（float） |
| `//` | 整除 | `10//3`：结果为整数（int） |
| `%` | 取余/求模 | `10%3`：结果为 1（10 除 3 取余数） |
| `**` | 幂指数 | `10**3`：10 的 3 次方 |

- 优先级：`**` > `*` `/` `//` `%` > `+` `-`。
- 涉及浮点数的算术运算时**可能会损失精度**：计算机底层基于二进制存储和处理数据，二进制无法准确表示所有小数。

### 4.2 赋值运算符

赋值运算符用于将值（或表达式的结果）保存到变量中（把右边的值赋给左边的变量）。

| 运算符 | 描述 | 实例 |
|--------|------|------|
| `=` | 赋值运算符 | 右边的结果赋值给左边的变量 |
| `+=` | 加法赋值 | `num += 2` 等效于 `num = num + 2` |
| `-=` | 减法赋值 | `num -= 2` 等效于 `num = num - 2` |
| `*=` | 乘法赋值 | `num *= 2` 等效于 `num = num * 2` |
| `/=` | 除法赋值 | `num /= 2` 等效于 `num = num / 2` |
| `%=` | 取余/取模赋值 | `num %= 2` 等效于 `num = num % 2` |
| `//=` | 取整除赋值 | `num //= 2` 等效于 `num = num // 2` |
| `**=` | 幂赋值 | `num **= 2` 等效于 `num = num ** 2` |

### 4.3 比较运算符

也称关系运算符，用于比较两个值之间的关系。会计算运算符两边的表达式，然后返回一个布尔值（`True` 关系成立，`False` 关系不成立）。

| 运算符 | 描述 | 实例 |
|--------|------|------|
| `==` | 等于 | `a == b` 判断 a 是否等于 b |
| `!=` | 不等于 | `a != b` 判断 a 是否不等于 b |
| `>` | 大于 | `a > b` |
| `>=` | 大于等于 | `a >= b` |
| `<` | 小于 | `a < b` |
| `<=` | 小于等于 | `a <= b` |

### 4.4 逻辑运算符

用于连接多个条件（布尔）表达式（值为"真"或"假"），并返回一个最终布尔结果。

| 运算符 | 描述 | 实例 |
|--------|------|------|
| `and` | 逻辑（并且） | 同时成立才符合条件 |
| `or` | 逻辑（或者） | 只要有一个符合要求即可 |
| `not` | 逻辑（取反） | 取反操作，真变假，假变真 |

## 5. if 条件判断

### 5.1 基本格式

只有满足指定条件才会执行对应的代码逻辑。

- 要判断语句的结果，必须是**布尔型**。
- `True` 会执行 if 内的代码，`False` 不会。
- 缩进（按一下 Tab 键）表示归属于上方的 if 代码块。

```python
if 要判断的条件:
    条件成立时要执行的操作
```

### 5.2 if…else

```python
if age >= 18:
    print("成年")
else:
    print("未成年")
```

- `else` 不需要判断，当 if 条件不成立时，`else` 就执行了。
- `else` 代码块也需要缩进（Tab）。

### 5.3 if…elif…else

满足第 1 个条件，就不会判断第 2 个和第 3 个部分；第 1 个条件不成立，才会判断第 2 个条件；1 和 2 都不成立，才会进入 `else`。

```python
if score >= 90:
    print("优秀")
elif score >= 60:
    print("及格")
else:
    print("不及格")
```

### 5.4 模式匹配 match…case

结构模式匹配就是用一个清晰的**模板**去精准匹配数据的结构和内容，匹配成功则执行相应的操作。

执行流程：

1. 首先计算 `match` 指定的表达式的值。
2. 从上到下依次和 `case` 后面的值进行匹配，匹配成功就执行语句。
3. 如果前面所有的 `case` 都没有匹配上，就会执行默认的 `case _`。

在 match-case 语句中，还可以对某个特定模式进行额外的条件限制：

```python
match 表达式:
    case 模式 if 条件:
        ...
    case _:
        ...


name = "python"
match name:
    case "python" if len(name) > 3:
        print("是 python")
    case "java":
        print("是 java")
    case _:
        print("不知道")
```

## 6. 循环

### 6.1 while 循环

while 循环是通过**条件表达式**来控制是否要进行下一次循环。

```python
while 条件表达式:
    循环体语句1
    循环体语句2
    ...
else:
    条件为False，循环正常结束时执行
```

- `break`：只能出现在循环中，表示**完全终止**循环，跳出循环体。
- `continue`：只能出现在循环中，表示**跳出本次循环**，继续下一次循环。

### 6.2 for 循环

while 通过条件表达式控制循环；而 for 循环本质是一种**轮询遍历机制**，对一批内容进行逐个处理。

```python
for 元素 in 待处理数据集:
    循环体代码（对元素进行处理）
else:
    循环结束时执行的代码      # 可选
```

```python
msg = "Hello-Python"
for i in msg:
    print(i)
else:
    print("循环结束")
```

这个代码的输出是把 `Hello-Python` 这个字符串里的字符一个一个地输出出来。

### 6.3 range 语句

作用：生成指定的数字规则。

| 用法 | 含义 | 示例结果 |
|------|------|----------|
| `range(end)` | 从 0 开始到 end 结束（不含 end 本身） | `range(5)` → 0,1,2,3,4 |
| `range(start, end)` | 从 start 开始到 end 结束（不含 end） | `range(2,8)` → 2,3,4,5,6,7 |
| `range(start, end, step)` | 增加步长 step（不含 end） | `range(0,10,2)` → 0,2,4,6,8 |

### 6.4 嵌套循环

```python
for 元素 in 待处理数据集1:
    循环体的代码1
    循环体的代码2
    for 元素 in 待处理数据集2:
        循环体的代码1
        循环体的代码2
        ...
    ...
```

### 6.5 print 的 end 参数

`print()` 自带换行效果，每一次执行都会输出到新的一行。在括号中加入 `end=` 可以修改结束符：`print(end=" ")` 表示每一次输出以空格结束，原本默认为 `\n`（换行）。

### 6.6 随机数

```python
import random                              # 引入 random 模块
random_number = random.randint(1, 100)     # 生成 1-100 之间的一个随机数
```

## 7. 数据容器概述

数据容器是一种可以容纳多份数据的数据类型。容纳的每一份数据称之为一个**元素**，每一个元素都可以是任意类型的数据，如字符串、数字、布尔。

根据 **是否支持重复元素**、**是否可以修改**、**是否有序**，数据容器分成五类：

- 列表（list）
- 字符串（str）
- 元组（tuple）
- 集合（set）
- 字典（dict）

> 序列类型：容器中的元素按特定顺序排列、可通过索引访问的容器类型，称之为序列。

## 8. 列表（list）

### 8.1 定义与特点

列表是数据容器中的一类，一次性可以储存多个数据（元素）。

```python
列表名称 = [元素1, 元素2, 元素3, ...]
s = [54, 15, 75, 108, 23, 78, 75]
```

特点：

1. 可以储存不同类型的元素。
2. 元素有序、可以重复、元素可以修改。

### 8.2 索引与增删改查

> 通俗理解：索引像队伍里的号码牌——正向从 0 开始数，反向从 -1 倒着数。

- 从前往后（正向索引），下标从 0 开始；反向索引从 -1 开始。

```python
print(s[i])       # 查看
s[i] = 修改内容    # 修改
del s[i]          # 删除
```

### 8.3 列表-切片

切片是指对操作的数据截取其中一部分的操作。列表、字符串、元组都支持切片操作。

语法：`序列数据[开始索引:结束索引:步长]`

- **不包含**结束索引位置对应的元素。开始索引未指定默认为 0；结束索引未指定默认为列表长度（直到列表末尾）；步长未指定默认为 1。
- 索引采用正向、反向索引都可以。
- 步长是选取间隔，默认步长为 1。

```python
s = ["A", "C", "E", "B", "D", "E", "G"]
s[0:5:1]    # ["A", "C", "E", "B", "D"]
s[0:5:2]    # ["A", "E", "D"]
```

### 8.4 列表-常用方法

> 通俗理解：方法就像是物品具备的能力或功能。比如手机的打电话、发短信和拍照这些功能就叫做方法，而手机本身叫做对象。

| 方法 | 作用 | 样例 |
|------|------|------|
| `append()` | 在列表的尾部追加元素 | `s.append(1)` |
| `insert()` | 在指定索引之前插入该元素 | `s.insert(0, 91)` |
| `remove()` | 移除列表中第一个匹配到的值 | `s.remove(75)` |
| `pop()` | 删除指定索引的元素（默认删最后一个） | `s.pop(2)` / `s.pop()` |
| `sort()` | 对列表进行排序（必须类型一致） | `s.sort()` |
| `reverse()` | 反转列表元素 | `s.reverse()` |
| `sum()` | 求和列表中的元素 | `sum(列表名)` |
| `len()` | 获得列表的长度 | `len(列表名)` |
| `min()` | 获取列表最小值 | `min(列表名)` |
| `max()` | 获取列表最大值 | `max(列表名)` |
| `count()` | 获取元素在列表中出现的次数 | `列表名.count(元素)` |

补充要点：

- `sort()` 的排序可以通过**匿名函数**来控制排序方式（其中的 `item` 指列表中的每一个元素），还可以配合 `reverse` 参数使用。
- Python 中两个列表相加可直接用 `+` 连接。
- `pop()` 方法在删除指定索引位置的元素后，会**返回该元素**。

```python
s = [12, 2, 32, 2]
e = s.pop(1)
print(e)      # 2
```

### 8.5 解包与组包

- **解包**：将列表一类的容器解开成一个一个独立的元素。用法：`*num_list`（`*` 即为运算符）。
- **组包**：将多个值合并到一个容器（元组、列表）中。

### 8.6 成员查询

```python
if 元素 in 列表名:      # 查询列表中是否存在这个元素
    ...
if 元素 not in 列表名:  # 反之
    ...
```

### 8.7 列表推导式

列表推导式是按照一定的规则快速生成一个列表的方法。

```python
# 语法：[要插入的值 for i in 序列/列表]
num_list = [i ** 2 for i in range(1, 21)]        # 生成 1-20 的平方列表

# 语法：[要插入的值 for i in 序列/列表 if 条件]
num_list1 = [i ** 2 for i in num_list if i % 2 == 0]
# 含义：从一个数字序列中提取所有偶数，并计算平方，组成一个新的列表
```

## 9. 字符串（str）作为容器

字符串是字符的容器，一个字符串中可以存放任意数量的字符，如 `"Python"`、`'Python'`、`"""Python"""`。

特点：**不可变性**（无法修改）、**有序性**、**可迭代性**。

字符串的每一个字符元素都有其对应的下标（索引），通过索引就可以获取对应的元素（索引规则和列表一致）。

### 9.1 字符串-切片

语法：`序列对象[开始索引:结束索引:步长]`

- 不包含结束索引位置对应的元素。
- 正向、反向索引都可以。
- 步长是选取间隔，默认步长为 1（如果是 -1，表示从后往前）。

```python
s = "Python"
s[0:5:1]        # "Pytho"
s[0:5:2]        # "Pto"
s[-1:-5:-1]     # 步长取负数时，前面的索引也需要用负数
```

### 9.2 字符串-常用方法

| 方法 | 作用 | 样例 |
|------|------|------|
| `find()` | 在字符串中查找子串，返回第一次出现的索引位置，找不到返回 -1 | `s.find('py')` |
| `count()` | 统计子串在字符串中出现的次数 | `s.count('H')` |
| `upper()` | 将字符串中的所有字母转换成大写 | `s.upper()` |
| `lower()` | 将字符串中的所有字母转换为小写 | `s.lower()` |
| `split()` | 将字符串按指定分隔符分割成列表 | `s.split(' ')` |
| `strip()` | 去除字符串两端的空白字符或指定字符 | `s.strip()` / `s.strip('*')` |
| `replace()` | 将字符串中的指定子串替换成新的子串 | `s.replace('H', 'C')` |
| `startswith()` | 检查字符串是否以指定子串开头，返回布尔值 | `s.startswith('P')` |
| `endswith()` | 检查字符串是否以指定子串结尾，返回布尔值 | `s.endswith('P')` |

## 10. 元组（tuple）

### 10.1 定义与特点

元组是**不可变的序列**，类似于列表，但创建后不能修改。

特点：

- 可以存储不同类型的元素。
- 元素可以重复、有序、**不可以修改**（支持索引访问、切片）。

```python
# 定义元组
t1 = (1, 4, 2, 2, 2)

# 定义空元组
t2 = ()
t3 = tuple()

# 定义单元素元组，需要加一个逗号
t4 = (100,)
```

### 10.2 元组常用方法

- `count()`：统计某元素在元组中出现的次数。
- `index()`：查找某个元素在元组中的索引位置（第一次出现的位置），如果该元素不存在将报错。

### 10.3 元组-组包和解包

- **组包（Packing）**：将多个值合并到一个容器（元组、列表）中。
- **解包（Unpacking）**：将容器（元组、列表）解开成独立的元素，分别赋值给多个变量。

```python
# 定义元组，组包
t1 = (5, 7, 9, 1)
a, b, c, d = t1          # 基础解包

t2 = 5, 7, 9, 1          # 组包
x, *y, z = t2            # 扩展解包：x 为 5，y 为 [7, 9]，z 为 1
s, *o = t2               # s 为 5，o 为 [7, 9, 1]
```

在元组解包时，`*` 表示收集剩余的所有元素，允许我们处理不确定数量的元素（生成列表，以便进行下一步处理）。

### 10.4 元组解包实例

在一些案例中会涉及到用复杂的元组进行学生成绩录入和计算，代码大概是这样的：

```python
students = (
    ("S001", "王林", 85, 92, 78),
    ("S002", "李慕婉", 92, 88, 95),
    ("S003", "十三", 78, 85, 82),
    ("S004", "曾牛", 88, 79, 91),
    ("S005", "周轶", 95, 96, 89),
    ("S006", "王卓", 76, 82, 77),
    ("S007", "红蝶", 89, 91, 94),
    ("S008", "徐立国", 75, 69, 82),
    ("S009", "许木", 86, 89, 98),
    ("S010", "通天", 66, 59, 72)
)

avg1 = []
print("学号\t姓名\t语文\t数学\t英语\t平均分")
for i in students:
    total = i[2] + i[3] + i[4]
    avg = total / 3
    avg1.append(avg)
    print(f"{i[0]}\t{i[1]}\t{i[2]}\t\t{i[3]}\t\t{i[4]}\t\t{avg:.1f}")
```

最后一行的 `{i[0]}\t{i[1]}\t{i[2]}...` 在代码较多之后不便于阅读和修改，可以用元组解包来改写，使代码更具可读性：

```python
for id, name, chinese, math, english in students:
    total = chinese + math + english
    avg = total / 3
    print(f"{id}\t{name}\t{chinese}\t\t{math}\t\t{english}\t\t{avg:.1f}")
```

把 `for i in students` 改为 `for id, name, chinese, math, english in students` 后，最后一行就变成了具名变量，代码的可读性大大增加，便于程序员的工作。

## 11. 集合（set）

### 11.1 定义与特点

集合是一种**无序**、**不可重复**、**可修改**的数据容器（输入了重复的数据也会自动去重）。

```python
s1 = {"C", "D", "X", "T", "O", "U"}

# 定义空集合
s2 = set()
```

> 空集合的定义**不可以**使用 `{}`，`{}` 表示的是空字典；由于集合是无序的，因此不支持下标索引访问。

### 11.2 集合常用方法

| 操作 | 含义 | 样例 |
|------|------|------|
| `add()` | 添加元素到集合中 | `s1.add('t')` |
| `remove()` | 移除集合中的指定元素 | `s1.remove('t')` |
| `pop()` | 随机删除集合中的元素并返回 | `e = s1.pop()` |
| `clear()` | 清空集合 | `s1.clear()` |
| `difference()` | 求两个集合的差集（包含第一个集合、不包含第二个集合的部分） | `s1.difference(s2)` |
| `union()` | 求两个集合的并集 | `s1.union(s2)` |
| `intersection()` | 求两个集合的交集 | `s1.intersection(s2)` |

### 11.3 集合运算符

| 运算符 | 含义 | 等价写法 |
|--------|------|----------|
| `&` | 交集 | `s2 = s1 & s3` |
| `-` | 差集 | `s1 - s2` 等价于 `s1.difference(s2)` |
| `\|` | 并集 | `s1 \| s2` 等价于 `s1.union(s2)` |

集合也可以使用推导式：

```python
{s for s in set1 if s not in set2}   # 等价于 set1.difference(set2)
```

## 12. 字典（dict）

### 12.1 定义与特点

字典的数据类型为 `dict`，里面存储的是键值对（`key: value`）类型的数据，可以根据键（key）找到对应的值（value）。每一个键都对应一个值，通过 key 可以快速找到对应的 value。

特点：键值对存储、**键不能重复**、可修改。

```python
# 定义字典
dict1 = {"a": 100, "b": 608}

# 定义空字典
dict2 = {}
dict3 = dict()

# 根据 key 获取 value
score = dict4["李思"]

# 修改 value
dict5["李思"] = 688
```

- value 可以是任意类型的数据，而 **key 不能为可变类型**（如列表、集合、字典）。
- 字典没有索引下标，不能根据索引获取值，只可以根据 key 获取 value。

### 12.2 常用操作

| 类型 | 操作 | 含义 | 样例 |
|------|------|------|------|
| 添加 | `名称[key] = value` | 往指定字典中添加键值对 | `dict["a"] = 688` |
| 删除 | `名称.pop(key)` | 删除指定的键，并返回该键对应的值 | `score = dict.pop("a")` |
|  | `del 名称[key]` | 删除字典中指定的键值对 | `del dict["a"]` |
| 修改 | `名称[key] = value` | 修改指定键对应的值 | `dict["a"] = 658` |
| 查询 | `名称[key]` | 根据键获取值 | `dict["a"]` |
|  | `名称.get(key)` | 根据键获取值 | `dict.get("a")` |
|  | `名称.keys()` | 获取所有的键 | `dict.keys()` |
|  | `名称.values()` | 获取所有的值 | `dict.values()` |
|  | `名称.items()` | 获取所有的键值对 | `dict.items()` |

字典可以通过 `keys()`、`values()`、`items()` 进行循环遍历。

## 14. 函数基础

### 14.1 函数定义与调用

函数是组织好的、可重复利用的、用来实现特定功能的代码片段。

```python
# 定义函数
def 函数名(参数列表):
    函数体
    ...
    return 返回值

# 调用函数
函数名(参数)
```

```python
def out_line():
    print("----------")

out_line()
```

> 函数定义时的参数列表与返回值语句是可有可无的（由需求决定）。函数必须**先定义后调用**执行；函数定义时内部代码并未执行，在调用时才执行。

### 14.2 参数与返回值

- 参数列表里的参数叫做**形参**，只能在函数内使用（局部变量）。
- 调用时传入的参数叫做**实参**，顺序必须要和函数里的形参一样。
- `return` 语句只有返回功能，没有打印功能，如果要输出，需要结合 `print()` 函数来实现。
- 如果返回值有多个，多个返回值之间用逗号分隔，多个返回值会封装到**元组（tuple）**之中。

### 14.3 函数的说明文档

它是写在函数开头、用三引号包裹的字符串，用于解释函数的功能、参数、返回值等信息，方便调用者清楚函数的具体作用及细节。

```python
def circle(r):
    """
    计算圆的面积
    :param r: 半径
    :return: 面积
    """
    return 3.14 * r ** 2
```

查看函数说明文档：

- 使用 `help` 函数，比如 `help(circle)`。
- 鼠标悬浮在函数上自动展示（推荐）。

### 14.4 函数的嵌套调用

它是指在一个函数中，又调用了另外一个函数。函数调用遵循**栈结构**，最后被调用的函数最先返回，即 LIFO（Last In First Out，后进先出）。

```python
def function_a():
    ...
    function_b()
    ...

def function_b():
    ...
```

## 15. 函数进阶

### 15.1 变量的作用域

作用域指的是变量的作用范围（标识这个变量在哪里可以使用，在哪里不可以使用）。

| 类型 | 定义位置 | 可用范围 |
|------|----------|----------|
| 全局变量 | 函数之外定义（通常在文件顶部） | 整个文件中（包括函数内）都可以使用 |
| 局部变量 | 函数内部定义 | 只能在该函数内部使用，外部无法访问；函数执行完毕后自动销毁 |

### 15.2 global 关键字

`global` 用于明确告诉 Python 解释器：在函数中要使用全局变量，使得可以在函数中修改全局变量的值。

```python
global xxx
```

在基于 `global` 声明全局变量时，要**先声明，再使用**。

注意：

- 尽量避免在函数中使用全局变量，因为会使代码难以维护和调试。
- 考虑使用函数参数和返回值来传递数据，而不是依赖全局变量。
- `global` 主要用在程序的状态、配置和计数器等场景中。

### 15.3 传参方式

传参方式指的是在调用函数时，传递实参的方式。

**位置参数**：调用函数时根据函数定义时的位置来传递参数。要求调用时参数顺序与定义时参数顺序完全一致。

**关键字参数**：调用时以函数定义时的形参名称作为关键字，以"键=值"的形式传递参数（不要求顺序）。

> 位置参数和关键字参数可以混用，但必须保证**关键字参数在位置参数之后**（关键字参数之间没有顺序要求）。

两种传参方式对比：

| 方式 | 优点 | 缺点 | 场景 |
|------|------|------|------|
| 位置参数 | 简洁 | 可读性差，易出错，维护难 | 参数少（≤3）且顺序自然 |
| 关键字参数 | 可读性强，易维护和扩展 | 代码繁琐 | 参数较多，或易混淆的场景 |

### 15.4 默认参数

也称缺省参数，用于在定义参数时为参数提供默认值，调用时可以不传递有默认值的参数。

注意：

1. 默认参数必须放在没有默认值的参数**后面**，一个函数在定义时可以设置多个默认参数。
2. 函数调用时，如果给默认参数传递了值，则会覆盖默认值；如果没有传递，则直接使用默认值。

```python
def greet(name, msg="你好"):
    print(f"{msg}，{name}")
```

### 15.5 不定长参数

也叫可变参数，用于函数定义及调用时参数个数不确定（0 个或多个）的场景。

**位置传递（`*args`）**

```python
# 定义函数
def calc_data(*args):
    ...

# 调用函数
data = calc_data(10, 20, 30)
```

- 传递的所有匹配的位置参数都会被 `args` 变量收集，合并封装为一个**元组**（注意不会封装关键字参数）。
- `args` 只是约定俗成的变量名，并不是关键字，可以使用任何合法的名称（如 `*data`）。

**关键字传递（`**kwargs`）**

```python
def make_tea(**kwargs):
    ...

make_tea(sugar="少糖", ice="去冰")
```

- 参数是以"键=值"形式传递的关键字参数，这些参数都会被 `kwargs` 接收，并合并封装为一个**字典**。
- `kwargs` 只是约定俗成的变量名，并不是关键字，可以使用任何合法的变量名（如 `**options`）。

**应用场景**

- `*args` 适用于处理数量不确定的**数据**。
- `**kwargs` 适用于处理数量不确定的**选项**（函数的配置参数，用来定制函数的行为）。

### 15.6 参数类型

- 普通参数：数字、字符串、布尔、列表、元组、集合、字典等。
- 特殊参数：**函数**（把函数本身作为参数传入，由接收方识别并执行）。

### 15.7 匿名函数

它是指没有名称的函数，需要通过 `lambda` 表达式来声明，可以简化简单函数的编写（单行表达式）。

```python
lambda 参数: 表达式

# 例：按列表元素的第二项排序
s.sort(key=lambda item: item[1])
```

注意：

- 函数逻辑比较简单（单行表达式）且只在一个地方使用时，可以考虑使用匿名函数简化书写（通常作为高阶函数的参数使用）。
- 匿名函数可以返回结果，也可以不返回结果。返回结果时**不需要写 `return`**，表达式的运行结果就是要返回的结果。

### 15.8 递归调用

在函数中自己调用自己的情况叫做递归调用（先层层递进，再逐层回归）。

```python
def fact(n):
    if n == 1:          # 终结点
        return 1
    return n * fact(n - 1)
```

> 注意：递归必须有一个**终结点**，否则会无限递归报错。

## 16. 类型注解

类型注解也叫类型提示，是 Python 中的一种语法特性，用于明确表示变量、函数参数和返回值的数据类型，从而使代码更清晰、更安全、更易维护。

```python
变量名: 类型 = 数据

age: int = 18
name: str = "涛哥"
```

> 注意：类型注解只起到语法提示作用，并不会影响程序运行的结果。

### 16.1 类型推断

类型推断是指 Python 解释器自动推断出变量、表达式或函数返回值的数据类型的能力，而无需开发者显式声明。

- 在对变量进行直接赋值，或者涉及变量的运算、容器的推导等场景时，解释器会自动推导出变量的类型。
- Python 是**动态类型语言**，添加的类型注解只是提示，并不是强制约束。

### 16.2 为什么使用类型注解

- 代码结构更清晰，代码逻辑更安全、易维护。
- 更准确的代码自动提示。
- 提前发现代码潜在问题。

### 16.3 函数-类型注解

为函数添加类型注解，主要就是为函数的**参数**和**返回值**添加类型注解：

```python
def add(a: int, b: int) -> int:
    return a + b
```

## 17. Python 模块

一个 `.py` 文件就是一个模块（module），模块是 Python 程序的基本组织单位。在模块中可以定义变量、函数、类以及可执行的代码。

作用：提高代码复用性、降低开发门槛、避免命名冲突。

### 17.1 导入模块

在使用模块中提供的功能之前，必须先导入再使用。

| 导入形式 | 代码样例 | 调用方式 | 调用样例 |
|----------|----------|----------|----------|
| `import 模块名` | `import random, os` | 模块名.功能名 | `random.randint(1, 10)` |
| `import 模块名 as 别名` | `import random as rd` | 别名.功能名 | `rd.randint(10, 100)` |
| `from 模块名 import 功能名` | `from random import randint, choice` | 功能名 | `randint(10, 100)` |
| `from 模块名 import 功能名 as 别名` | `from random import randint as rint` | 别名 | `rint(10, 100)` |
| `from 模块名 import *` | `from random import *` | 功能名 | `randint(10, 100)` |

> `random()`：获取随机数。

### 17.2 自定义模块

当开发一些复杂的项目时，为了让项目结构清晰、更便于项目的维护管理及代码的复用，可能会把一个项目拆分为若干个模块，例如：

```
project/
├── config.py        # 配置
├── session.py       # 会话
└── ai_partner.py    # 业务逻辑
```

> 注意：每一个 Python 文件都可以作为一个模块，模块的名字就是文件的名字（建议使用 Python 标识符规范命名）。
